# Terrafell

A survival game: dig anything, build anything, survive the night. Play alone or with up to 3 friends.

## Download (Windows)

1. Download **[TerrafellLauncher.exe](https://github.com/sehrcool72-code/Terrafell/releases/download/launcher/TerrafellLauncher.exe)**.
2. Run it. Windows may say it protected your PC from an unrecognised app: click **More info**, then **Run anyway**.
3. Click **Install** (about 530 MB download). The launcher keeps the game updated from then on.

## Playing together

- **Host:** load a world, press Esc, then choose **Play with friends**.
- **Friends:** in the main menu choose **Multiplayer** and enter the host's address. On the same network that is the host's local IP; over the internet it is their public IP, with port 7777 forwarded on their router.

This repository only holds the game's downloads.
